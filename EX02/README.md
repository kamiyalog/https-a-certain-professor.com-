# BADENDから始めましょう — CV確認機能・男性ボイス対応版

`index.html` をブラウザで開くと、関係者確認用の暗証番号画面から起動します。暫定暗証番号は `0701` です。認証後、音声の注意画面を約4.5秒表示し、案内人選択画面へ進みます。

暗証番号は静的ページ上の簡易的な閲覧制限です。一般公開時は、`game.js` 冒頭の `PREVIEW_GATE_ENABLED` を `false` に変更すると無効化できます。

本版は `バッドエンドから始めましょう_4話修正 (1).xlsx` を物語本編の正本として、一～四章の本文・分岐・介入・背景・立ち絵・SE・演出指定を再反映した版です。案内人台詞は、別途受領した最新版 `バッドエンドから始めましょう_案内人収録台本(1).xlsx` を基準にしています。解放済みの章は引き出せる革装丁の本、未解放章は封印された暗い本として表示されます。章を選んだ後は、暗色のカード式ツリーで話を選択します。章内の未解放の話は、存在自体を表示しません。

- 案内人選択前の音声に関する注意表示

- 第4章「誰かが見ている」の全ルート

- 第4章の三つのBAD ENDと、三段階の介入回避
- 第4章の電話演出（発信中／着信中／通話中／ノイズ／通話終了、発話連動の波形）

画面は二段階です。最初の章選択画面で、互いに独立した「第1章」～「第4章」を選びます。各章の内部構成は章ごとに異なり、第1章には「1話」だけが存在します。内部管理用IDは画面に表示しません。

第1章を完了すると「第2章」と、その内部ツリー最上段にある「1話」が解放されます。第2章・第3章は「1話 → 2話／2話（改変）」の二話構成です。台本上の `1-〇` 系は1話に内包し、`2-〇` 系を2話、1話から分岐する `3-〇` 系を2話（改変）として扱います。各章の未解放の話は、カード・LOCK表記・接続線を含めて一切表示しません。通常版／改変版は条件を満たして解放された時点で初めてツリーに現れます。

第4章は「1話 → 2話／2話（改変） → 3話／3話（改変）」の三話構成です。通常側は3話でBAD END①へ到達します。改変側は、2話の内部で `4-2`、3話の内部で `5-2` へ直接遷移し、三回目の介入成功後に最終案内人語りとエンディング画面へ進みます。正本上に独立した4話カードはないため、ラストは3話（改変）から直接接続しています。

背景と立ち絵は、正本に記載された素材名を保持しながら差し替えられる構造です。`正式採用された背景.zip` の背景23点に、正式採用された「夜の公園」、机上を空にした「黒江第三ビル・407号室」、新規の「病室512・深夜・覚醒版」を加えた背景26点を、ファイル名に対応する場面へ割り当てています。病室504、編集部の資料表示、オフィス・病室・病棟廊下・ナースステーションなどの朝／夕方／夜／深夜も、正式画像をそのまま表示します。時間帯を色調補正で作ったり、別場面の画像を代用したりはしません。同一画像を使う場面は一つの正式採用ファイルを共有し、内容が重複する別名ファイルや未参照素材は同梱していません。

旧別名の重複背景として、`break-room.png`、`convenience-store-front.png`、`hospital-corridor.png`、`hospital-station.png`、`office.png`、`station-lockers.png`、`twilight-road.png`、`woman-down.png` などを除外しています。ゲーム内では、それぞれ対応する正式採用名の画像だけを参照します。

本文中の人物立ち絵は一人表示を中央に置き、全身ではなくウエストアップを中心に表示します。背景または場面が切り替わる時点で、立ち絵は一度消去します。ゲーム内で使用する人物素材7点は、すべて実透過PNGとして再処理し、白・黒・マゼンタ背景上で輪郭を再確認しています。小宮山直子は対面場面だけ通常立ち絵を表示し、通話中は立ち絵を出さず、右上のVOICE LINKだけを表示します。コンビニ前と灰色のカーディガンの女性・紙袋も追加添付の専用素材を使用します。

病室512は同一人物・同一テイストに統一しています。夜版は朝版を基準にした就寝中の画像、深夜版はマスクを装着したまま目を覚ましている画像です。旧深夜版は `病室512・深夜・問題時.png` として3-37～3-39、および改変側の3-2-8～3-2-17に使用し、通常側の3-40からBAD END②までは黒背景に切り替えます。

本版では、SEと環境音を使用しません。シナリオデータ内の `se` 欄は制作資料として残していますが、ゲーム側にはSEの再生処理・音源参照・音源ファイルを含めていません。`fourth.mp3` も使用せず、該当箇所はテキストのみです。

案内人ボイスは再生処理とファイル名の対応だけを実装しています。CV音声をAIへ取り込まない取り決めのため、本ZIPにはWAVを含めていません。受領済みの男性WAV90点を `assets/voice/` へ、ファイル名を変えずに配置してください。必要な範囲は次のとおりです。

- `M-INTRO-001.wav` ～ `M-INTRO-013.wav`
- `M-EP1-001.wav` ～ `M-EP1-018.wav`
- `M-EP2-001.wav` ～ `M-EP2-017.wav`
- `M-EP3-001.wav` ～ `M-EP3-018.wav`
- `M-EP4-001.wav` ～ `M-EP4-024.wav`

女性版は同じボイスIDの先頭を `F-` にしたファイル名へ自動対応します。

案内人は、選択画面では黒背景付きの全身画像、導入・語りでは透過立ち絵を腰上に拡大して表示します。透過立ち絵は `assets/narrator-male-stand.png` と `assets/narrator-female-stand.png` です。最終ENDページのお辞儀画像 `assets/narrator-male-bow.png` と `assets/narrator-female-bow.png` も、市松模様を焼き込んだ画像ではなく実際にアルファ透過したPNGです。

案内人のCV名は、`game.js` 冒頭の `NARRATOR_CV` で管理しています。現在は男性 `もこ山モコ`、女性 `鯱子` です。案内人選択画面とクレジットの両方へ反映されます。

全画面の下部に、フィクションであることの注意書きを表示します。

文章送りでは行ごとに画面内容を更新し、背景・立ち絵・電話状態・指定演出を同期します。案内人フェーズと本編フェーズの切り替わりに加え、背景が変わるすべての箇所で、約1.35秒のフェードアウト、短い黒画面、約1.35秒のフェードインを行います。第1章38行目の道から公園への切り替えも、この暗転で処理します。赤／白フラッシュ、暗転、画面揺れ、歪み、モニター表示など、シナリオで指定された演出も反映しています。

ゲーム画面内の本文・ボタン・立ち絵・注意書きは、ブラウザの文字選択と画像ドラッグを無効にしています。連打や軽いドラッグで青い選択表示が出ることはありません。テキスト履歴内の文章だけは、従来どおり選択・コピーできます。

画像作成・組み込み、CV表記、第一章案内人セリフ、限定公開、ボイス確認機能の対応状況は `PENDING_TASKS.md` に記録しています。
